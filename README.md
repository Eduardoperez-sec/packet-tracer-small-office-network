# PérezTech Solutions — Enterprise Network Infrastructure

## Project Overview

This project documents the design, configuration, and troubleshooting of an enterprise-style network using Cisco Packet Tracer.

The project is part of my hands-on learning journey while studying networking and preparing for the Cisco CCNA certification.

The goal is to progressively build a small enterprise network and practice essential networking concepts, configurations, and troubleshooting techniques.

## Technologies and Tools

- Cisco Packet Tracer
- Cisco IOS
- Cisco Routers and Switches
- IPv4 Addressing and Subnetting
- Ethernet and TCP/IP
- Windows PCs
